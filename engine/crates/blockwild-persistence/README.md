# blockwild-persistence

Deterministic save authority for the hybrid Rust engine.

This crate owns the R8 contracts that must be identical in native tools and
browser Wasm:

- location-sharded record addresses and stable record kinds;
- revision-checked, all-or-nothing journal transactions;
- payload, transaction, checkpoint, migration, and state hashes;
- dirty-record checkpoint compaction without whole-world rewrites;
- legacy migration bundles that fingerprint but never mutate the source;
- newest-complete-checkpoint recovery and explicit repair diagnostics;
- checksum-protected portable transaction/checkpoint/migration wire records.

IndexedDB remains a browser platform adapter. It must execute a prepared Rust
transaction in one `readwrite` transaction, report quota/storage failures, and
return the durable record/checkpoint hashes for Rust readback validation. The
adapter may not reinterpret rules, repair revisions, or delete the legacy
namespace during migration.

## Native inspection

After building the workspace:

```text
blockwild-tools save-inspect path/to/record.bwps
```

The inspector decodes and checks the outer checksum, canonical record hash,
schema, record count, and byte total without starting a renderer.

## Verification

```text
cargo test -p blockwild-persistence
cargo clippy -p blockwild-persistence --all-targets -- -D warnings
```

The fixture tests include exact hashes generated by the TypeScript parity
oracle. Any divergence is a release veto until an explicit schema migration is
introduced.
